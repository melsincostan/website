Dubious Doohickeys

Some are made to fill a debugging or processing need, most of them are just made to see if it works and for fun.
  • reqpile: Listens for HTTP requests on a given port, dumps the request contents out on STDOUT and replies with 204 No Content
  • netmeow: Something somewhat like netcat, since it was faster to do this than figuring out some netcat tool for a windows VM with network but no internet access.
  • ssg: An approximation of a static site generator, using rust. It was used to generate a previous version of this homepage, along with a small blog part, that only ever had two articles.
